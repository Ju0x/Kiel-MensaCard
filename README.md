## Kiel-MensaCard

Android app that can read the balance from your student card.
It should work for every cafeteria card from the Studentenwerk SH, but currently it's only tested with the CAU card.

## Installation

You can install the app using the latest release: [https://github.com/Ju0x/Kiel-MensaCard/releases](https://github.com/Ju0x/Kiel-MensaCard/releases)

There you can download the APK file and install it.
